Building a native video recorder and editor for Mac, written in Swift. Not public yet.

## Projects

- **[Open Sea](https://opensea.rafaelcesar.com)** ([code](https://github.com/rafaelcesartec/open-sea)): the ocean seen from above, live, with sea animals at their real size. Each one decides on the spot what to do: hunt, flee, swerve.
- **[Cortex](https://github.com/rafaelcesartec/cortex)**: a plugin for Claude Code and Codex that organizes a business's context and runs marketing and sales.
- **[DeskcommCRM](https://github.com/melgarafael/DeskcommCRM)**: open source CRM with AI agents and WhatsApp. I built its test mode (the AI only answers approved numbers until the setup is validated), automated the OpenAI and Anthropic SDK and model-list updates, and migrated it to Tailwind CSS v4.
